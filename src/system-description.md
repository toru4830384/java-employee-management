# 社員管理システム API 機能説明

このシステムは、社内で利用する社員情報を管理するためのAPIです。

主な機能は以下の4つです。

## 1. 社員情報取得 (GET)

社員IDを指定して、登録されている社員情報を取得します。

取得できる情報：
- 氏名
- 氏名カナ
- 役職
- システムロール
- 住所
- 電話番号
- 生年月日
- 性別

## 2. 社員情報登録 (POST)

新しい社員情報を登録します。

登録時には必須項目の入力チェックを行い、正常な場合のみデータベースへ登録します。

登録できる情報：
- 氏名
- 氏名カナ
- 役職
- システムロール
- 郵便番号
- 住所
- 電話番号
- 生年月日
- 性別

## 3. 社員情報更新 (PUT)

社員IDを指定し、登録済みの社員情報を更新します。

更新時は更新日時（updated_at）が更新されます。

## 4. 社員情報削除 (DELETE)

社員情報を論理削除します。

データを物理的に削除するのではなく、deleted_atに消去日時を設定することで消去済みとして管理します。

---

このAPIを利用することで、社員情報の登録・参照・変更・削除を一元管理できます。
